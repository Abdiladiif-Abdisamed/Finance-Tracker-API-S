# Personal Finance Tracker (Full Stack)

This bundle contains a ready-to-run backend (Node/Express/MongoDB, ESM) and a React frontend (Vite + Tailwind).

## Run Backend
```
cd backend
cp .env.example .env
# fill your Mongo URI and Cloudinary creds
npm install
npm run dev
```

## Run Frontend
```
cd frontend
npm install
npm run dev
```
Open http://localhost:5173
